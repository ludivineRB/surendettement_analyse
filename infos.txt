** API : 
la lancer : .venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8020
app/core/config.py : ajout de ANALYTICS_DB_PATH
app/core/analytics.py : connexion SQLite analytique + table d’overrides
app/schemas/analytics.py : schémas Pydantic
app/views/analytics_api.py : endpoints API
app/main.py : branchement du router /api/data
requirements.txt : ajout fastapi, sqlmodel, pydantic-settings, uvicorn
app/tests/views/test_analytics_api.py : test logique API
Endpoints disponibles :
GET    /api/data/health
GET    /api/data/departments
GET    /api/data/indicators
GET    /api/data/bdf
GET    /api/data/insee
GET    /api/data/joined
GET    /api/data/macro-overrides
POST   /api/data/macro-overrides
PATCH  /api/data/macro-overrides/{override_id}
/!\ : les ajouts et modifs se font dans une table différente : facto_macro_override
les exemples : 
curl "http://127.0.0.1:8020/api/data/departments?limit=5"
curl "http://127.0.0.1:8020/api/data/joined?departement_code=75&macro_indicator_code=P22_POP&limit=10"
curl -X POST "http://127.0.0.1:8020/api/data/macro-overrides" \
  -H "Content-Type: application/json" \
  -d '{"reference_year":2026,"departement_code":"75","indicator_code":"custom_indicator","indicator_name":"Indicateur custom","value":42.0,"source_note":"saisie manuelle"}'
