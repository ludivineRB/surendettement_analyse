LOT DE STABILISATION, GOUVERNANCE ET PRÉ-INDUSTRIALISATION
Date : 29 juillet 2026
Projet : surendettement_analyse

========================================================================
1. OBJECTIF DU LOT
========================================================================

Ce lot transforme le prototype de calcul territorial en une chaîne de données
plus reproductible, observable et préparée pour l’exploitation.

Il couvre :

- l’automatisation des imports Banque de France et INSEE ;
- l’historisation départementale 2023, 2024 et 2025 ;
- l’ajout d’une source rigoureuse pour l’endettement moyen ;
- la traçabilité persistante des exécutions ;
- des contrôles qualité bloquants ;
- l’étude de stabilité du modèle 1.2.0 ;
- des endpoints API spécialisés ;
- de nouveaux outils d’analyse Streamlit ;
- un premier socle Docker et PostgreSQL.

Le lot ne transforme pas le score en outil de décision individuelle. Le score
reste un indice statistique territorial comparatif.

========================================================================
2. SOURCES DE DONNÉES
========================================================================

2.1 Banque de France — baromètres mensuels

Les baromètres mensuels régionaux alimentent notamment :

- les dossiers de surendettement déposés ;
- le droit au compte ;
- les inscriptions au FCC.

Le pipeline conserve :

- l’URL de la page ;
- l’URL du document ;
- le nom du fichier ;
- l’empreinte SHA-256 ;
- les en-têtes HTTP ETag et Last-Modified lorsqu’ils existent ;
- le statut d’extraction ;
- la version de l’extracteur ;
- la période et le territoire.

Les téléchargements conditionnels permettent de repérer un document nouveau ou
modifié. Une nouvelle empreinte crée une nouvelle version de source sans
écraser l’ancienne.

2.2 Banque de France — typologie annuelle du surendettement

Les cahiers régionaux et départementaux 2023 et 2024 sont des PDF de 130 pages.
Les taux départementaux sont extraits géométriquement, colonne par colonne.

Le parseur gère :

- les noms avec tirets typographiques différents ;
- les apostrophes ;
- les accents ;
- les noms composés contenant un autre département, par exemple :
  Haute-Loire/Loire, Haute-Savoie/Savoie et Val-d’Oise/Oise ;
- les taux de pauvreté écrits avec ou sans décimale ;
- les blocs répartis sur deux colonnes.

Les classeurs 2025 fournissent directement les données départementales.

Couverture obtenue :

- 2023 : 96 départements sur 96 ;
- 2024 : 96 départements sur 96 ;
- 2025 : 96 départements sur 96.

2.3 INSEE — inflation

Série utilisée :

- identifiant INSEE : 011814630 ;
- indice des prix à la consommation ;
- ensemble des ménages ;
- France ;
- nomenclature Ensemble.

L’inflation mensuelle correspond au glissement sur douze mois :

    inflation(t) = (IPC(t) / IPC(t-12) - 1) × 100

L’inflation annuelle est la moyenne des glissements mensuels disponibles dans
l’année.

La valeur est nationale. Elle est donc identique entre territoires pour une
même période. Elle informe l’évolution temporelle mais ne différencie pas les
territoires au sein d’un même mois ou d’une même année.

2.4 INSEE Filosofi et données de contexte

Les informations de pauvreté et de revenu médian conservent explicitement leur
année source. Une valeur annuelle utilisée sur une période ultérieure reste
identifiable dans source_fragment.

Le chômage et la pauvreté 2023–2024 sont également extraits des contextes
territoriaux publiés dans les cahiers Banque de France, qui citent leurs sources
INSEE et leurs millésimes.

3. INDICATEUR D’ENDETTEMENT MOYEN
========================================================================

Une source rigoureuse a été trouvée dans les classeurs départementaux Banque de
France.

Chaque feuille départementale contient :

- l’encours global des dettes en milliers d’euros ;
- le nombre de dossiers traités ;
- l’endettement médian.

L’indicateur retenu n’est pas la médiane. Il est calculé par :

    endettement_moyen =
        encours_global_en_milliers_euros × 1 000
        / nombre_de_dossiers_traités

Libellé :

    Endettement global moyen par dossier traité

Code :

    endettement_moyen

Unité :

    euros

Version d’import :

    risk-score-bdf-mean-debt-v1

Une faute présente dans le classeur officiel 2024 est documentée :

    Indre-et-Loir → Indre-et-Loire

Résultat :

- 2023 : 96 valeurs annuelles ;
- 2024 : 96 valeurs annuelles ;
- 2025 : 96 valeurs annuelles répliquées sur 11 mois disponibles ;
- total : 1 248 observations.

Chaque observation mensuelle issue d’une valeur annuelle porte le type :

    annual_replicated_monthly

Les observations 2023–2024 portent le type :

    annual

========================================================================
5. MODÈLE 1.2.0 ET NORMALISATION
========================================================================

5.1 Pondérations

- dossiers pour 1 000 habitants : 30 % ;
- chômage : 20 % ;
- pauvreté : 20 % ;
- revenu médian : 15 %, direction négative ;
- endettement moyen : 10 % ;
- inflation : 5 %.

5.2 Normalisation active

La version 1.2.0 utilise un Min-Max winsorisé 
(la winsorisation : les valeurs extrêmes d'une série sont d'abord plafonnées à des percentiles limites (ex. 1 % et 99 %))
aux percentiles 5 et 95 de la
cohorte territoriale et de la période.

Une valeur inférieure au percentile 5 est ramenée à la borne basse. Une valeur
supérieure au percentile 95 est ramenée à la borne haute.

5.3 Bornes fixes candidates

Les bornes fixes candidates ont été calculées sur la référence départementale
2023–2024, soit 192 observations par indicateur disponible :

- dossiers pour 1 000 habitants : 1,531 à 3,4445 ;
- chômage : 5,155 % à 9,845 % ;
- pauvreté : 10,61 % à 19,68 % ;
- revenu médian : 20 775 € à 24 913,50 € ;
- inflation : 2,003 % à 4,894 %.

L’endettement moyen devra être réintégré au rapport de bornes après le nouvel
import et avant toute activation.

Ces bornes sont marquées :

    candidate_not_activated

Elles ne modifient pas les scores 1.2.0 déjà publiés. Une activation devra créer
une nouvelle version du modèle.

5.4 Analyse de sensibilité

Scénario de référence avec bornes fixes :

- corrélation des rangs : 0,99946 ;
- écart absolu moyen : 0,59 point ;
- écart maximal : 2,27 points.

Scénario à poids égaux :

- corrélation des rangs : 0,99215 ;
- écart absolu moyen : 6,51 points ;
- écart maximal : 16,74 points.

Scénario renforçant le poids des dossiers à 45 % :

- corrélation des rangs : 0,97453 ;
- écart absolu moyen : 3,67 points ;
- écart maximal : 11,44 points.

Conclusion :

- des bornes fixes 2023–2024 affectent peu les rangs et les valeurs ;
- la pondération influence davantage les scores absolus ;
- toute modification des poids doit faire l’objet d’une nouvelle version et
  d’une validation métier.

5.5 Comparaison 1.1.0 / 1.2.0

Pour 2024 :

- 96 départements comparés ;
- corrélation des classements : 0,993 ;
- écart absolu moyen : 7,99 points ;
- écart maximal : 22,89 points ;
- 36 changements de niveau de risque.

La version 1.2.0 conserve largement le classement mais réduit l’influence des
valeurs extrêmes sur les scores absolus.

7. ORCHESTRATEUR AUTOMATISÉ
========================================================================

Fichier :

    src/pipeline_orchestrator.py

Nom du pipeline :

    territorial-risk-refresh-v1

Commande :

    .venv/bin/python -m src.pipeline_orchestrator --from 2025-02

Options :

- --from : première période mensuelle obligatoire ;
- --to : dernière période optionnelle ;
- --department-years : millésimes départementaux ;
- --dry-run : simulation sans validation des écritures métier.

Étapes exécutées :

1. création/migration du schéma et des modèles ;
2. découverte et import des baromètres mensuels Banque de France ;
3. import des taux départementaux pour chaque millésime ;
4. harmonisation des contextes historiques ;
5. import de l’endettement moyen ;
6. import de l’inflation INSEE ;
7. recalcul de tous les scores régionaux ;
8. recalcul de tous les scores départementaux ;
9. contrôles qualité.

Le pipeline est idempotent : une observation possédant la même clé métier et
la même version source n’est pas insérée une seconde fois.
